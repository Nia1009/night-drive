Vibe Coding / 合集

三个可运行的原型

这三个项目都不是 PPT：需求定义、信息架构、交互与前端实现都由我自己完成， 它们现在是可以点开跑起来的原型。选它们的标准是同一条——能否把一种「工作方法」变成别人也能用的工具。

01

PRD 平台

REVIEW & KNOWLEDGE SYSTEM

用于沉淀需求说明与协作过程的 PRD 平台。HTML PRD 可以直接在线阅读，并支持评论、编辑和通知协同； 需求不再散落在文档与聊天记录里，评审、答疑与版本变更都留在同一处。公开版以匿名只读归档呈现。

  • 19 份真实 PRD 归档，按迭代分组检索
  • 文档正文 + 问答讨论流并排，评审上下文不丢失
  • 公开版移除写入、上传与邀请接口，仅保留只读能力

02

自动评测平台

AI EVALUATION WORKBENCH

自动执行评测脚本，在仿真环境中驱动 Agent 完成测试；经 AI 初判 + 人工复判 两阶段后， 可导出完整评测报告。它把「评测与验收」的隐性判断变成了可复现的链路，已被推理部门作为评测基建，并将扩展至推理链测评。

  • 覆盖测试集管理、任务运行、结果判定与失败归因
  • 保留版本回归对比，让「变好了吗」有据可查
  • 公开版为只读快照：不连接内部服务、不执行任务

03

AI 应用模版

OPEN CREATION TOOLKIT

为 Agent 提供可以直接搭建的应用骨架。普通用户不用理解节点与参数， 只要自定义功能、生成并填充素材，就能快速产出符合主站设计语言的完整应用——这是「自然语言生成 AI 应用」的落地形态。

  • 三套骨架：Creative Studio、Intent Media Editor、AI Character Setup
  • 统一组件与视觉约束，产物自动对齐主站设计语言
  • 上线两周实现日均发布 AI 应用 100+
